Phase 75: Note Memory Kind, Long-Record Admission, and Open Interchange
=======================================================================

Status
------

[ACTIVE]

Goal
----

Let an agent write a prose page as durable GoodMemory through the library, MCP,
HTTP, or CLI; store it verbatim; recall it under the default configuration;
render it with structure intact; export and import it as an open,
memoryfield-compatible pages directory; and browse it through an index-only
`MEMORY.md` plus topic files, without weakening any governance boundary or
benchmark protection. Source: the memory-as-data audit in
`docs/GoodMemory-Benchmark-Optimization-Research-2026-07.md` (2026-09-01) and
`adr/ADR-010-note-memory-kind-file-mirror-and-interchange.txt`.

Gate
----

- TDD: every step lands its failing test first. New logic lives in new modules
  so `tests/unit/architecture.boundaries.test.ts` ceilings hold.
- `note` is a taxonomy change (ADR-001): union + plane map + ADR-010. Notes are
  never sentence-split, are capped at 8,192 UTF-8 bytes, embed whole, and are
  excluded from the provider rerank pool.
- The projection pipeline version bumps once (`gm-projection-v6`) for the new
  source collection; the rebuild is per scope and fail-closed (ADR-008).
- Long-record admission ships opt-in (`retrieval.longRecordAdmission`) with
  legacy-first sequencing; the library default stays byte-identical. Fresh
  installed-host configs enable it only after a provider-free paired
  LongMemEval + LoCoMo diagnostic stays within the phase-69 protection rule
  (recall delta ≥ -0.01 per type/category, noise per question ≤ +8,
  behavioral fixtures identical).
- Interchange is a flat pages directory with frontmatter, `listing.md`, and a
  SHA-256 manifest, plus the export JSON envelope. No zip writer. Import is a
  named facade (`importMemory`), never an MCP tool.
- The file mirror is derived, read-only, regenerated wholesale after
  mutations, never read back, and off by default.
- The rendered-fragment frame is a localized data-not-instructions line, not a
  guardrail claim.
- No benchmark declaration, README table, or claim status changes.
